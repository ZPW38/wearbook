# 腕上书 · 安卓手表电子书阅读器

> **抬起手腕就能接着读。** 一个专为小屏幕重做的阅读器 —— 纯原生 Compose 绘制，跑在手表上，装得上、跑得动。

排版和渲染全部由系统原生完成，**安装包只有 1.2 MB**，装得进儿童手表那种小存储，覆盖安装秒完成。

**官网**：<https://zpw38.github.io/wearbook/> · **下载**：[Releases](releases)

## 下载安装

**最新版本**：从 [Releases](releases/latest) 下载 `wearbook-watch-*.apk`（Android 7.0 及以上）。

### ⚠️ 从旧版升级必须先卸载

v1.9.2 起改用**正式签名证书**（此前是 Android SDK 的调试证书）。签名不同，安卓不允许覆盖安装。

**卸载会清空书架和阅读进度。** 书放在「专属文件夹」里的话，重装后扫目录能收回书架，但进度保不住。

### 华为手表：只能手动装

华为会拦截 `adb install`（`INSTALL_FAILED_VERIFICATION_FAILURE: adb install not allowed!`），没有命令行绕过办法：

1. 用数据线把 APK 拷到手表的 `Download` 目录
2. 在手表上用文件管理器点开安装

### 其他安卓手表 / 手机

```bash
adb install -r wearbook-watch-1.9.2.apk
```

## 功能

### 📚 支持格式

| 格式 | 说明 |
|---|---|
| **TXT** | UTF-8 / GBK 自动识别；**能按「第X章 / 第X回 / Chapter N」切章**，认不出来才按长度硬切 |
| **EPUB** | 按 spine 取正文，**正文插图会显示**（点一下撑满屏看，还能左右切到本书其他插图），封面缩略图 |
| **MOBI / AZW·AZW3** | PalmDOC 解压，**按书自带的目录锚点切章** |
| **HTML** | 直接解析 |

### 📥 导书：六条路都能走

1. **手机扫码传书** —— 手表起一个局域网小网页并显示二维码，手机扫码后用浏览器把书推上来。**不用数据线、不用权限、不用在表盘上打字**（v1.9.0 新增）
2. **专属文件夹** —— `/sdcard/Android/data/com.webook.watch/files`，这个目录任何系统、任何权限都能读写。数据线或手机端工具放书进去即可
3. **链接导入** —— 填一个 http(s) 直链直接下载入库。**只做通用直链下载**：把字节流原样存成文件，不解析站点结构、不注入 Cookie、不做签名或反爬
4. **分享导入** —— 在微信 / MT 管理器里长按电子书 →「分享」→ 腕上书。走 `contentResolver` 流，**零权限**
5. **打开方式** —— 在其他应用里选「打开方式」→ 腕上书（已注册 epub / mobi / azw）
6. **扫目录收书** —— 书架标题栏的文件夹按钮，一键把 `Download` / `Downloads` / `Books` 里已下载的书收进来（只扫一层，跳过没下完的半成品，靠「路径+字节数」记账防重复）

### 📖 阅读体验

- **两种模式**：翻页（一屏一页）/ 滑动（整章连续上下滚）
- **续读精确到字**：进度记「第几章的哪一段的哪个字」，不是页码 —— 改字号、改行距、开关状态栏都不跳页；进程被回收也不丢
- **目录**：按书自带目录切章，**打开时自动跳到当前章**（连载几百章的书不用再从头翻）
- **全文搜索**：本书内搜索，**边找边出结果**，点结果直接跳到命中页
- **插图查看器**：正文插图点一下撑满屏，单指拖动看局部（手表双指缩放做不出来，所以不用捏合手势）；顶部「‹ 3 / 12 ›」切到本书其他插图，切图时缩放倍数保留、平移自动归位
- **漫画模式**：一屏一张整页图 / 点右前进点左回退 / 中间显隐工具栏 / 双击 2x 放大 / 预读下一张 / 表冠与音量键翻页
- **底部状态栏**：百分比 + 当前时间，可分开开关

### 🎨 排版与外观

- 字号 **14–26px**、行距 **1.3–2.2**，随时可调
- **日间 / 夜间各 4 套底色**：纸白 / 米黄 / 淡绿 / 浅灰 · 纯黑 / 深灰 / 深蓝 / 深棕
- **屏幕亮度**：阅读菜单「界面」里可调（含「跟随系统」开关）
- 深浅色跟随系统或手动切换，切换时背景带过渡动画
- 文字两端对齐（可选）、**圆屏安全边距**按短边等比推算（上下 7%、左右 2.8%）

### 🔊 听读与手感

- **系统 TTS 朗读**：读完本页自动翻页，0.5–1.5 倍速，朗读时保持常亮
- **自动翻页**：1~30 秒**无级可调**，滑动模式下滚到章末会自己接下一章
- **表冠 / 音量键翻页**：走 Activity 层接收，不依赖 Compose 焦点
- 点击屏幕两侧翻页，可关闭

### ⌚ 专为手表做的

- **纯原生 Compose 绘制**，DEX 内无 `webkit` 引用
- 操作逻辑针对极小屏幕重新设计（不是把手机界面缩小），菜单按钮都是「图标 + 文字」
- 沉浸式全屏、阅读时常亮
- **禁用手表固件层的侧滑返回**：从屏幕最左边划一下是翻页，不会误退出（返回键照常可用）

## 手表上列不出 epub / txt？看这里

如果你在应用里**一个电子书文件都列不出来**，不是 bug，是安卓的存储策略。

> **Android 11+**：只申请 `READ_EXTERNAL_STORAGE` 时，`File.listFiles()` 只能列出音乐、图片等**媒体文件**，电子书会被系统隐藏。需要「所有文件访问」权限，而**很多手表（尤其 Wear OS）的系统设置里根本没有这个开关**。
>
> **Wear OS 更彻底**：系统没有文件管理器，`ACTION_OPEN_DOCUMENT` 被解析到一个透明的空 Activity（`frameworkpackagestubs/.Stubs$DocumentsStub`）—— 点了既不弹选择器也不报错。

**所以请用这两条不依赖系统权限的路：**

1. **手机扫码传书**（最省事）—— 导入页点「手机传书」，手表显示二维码，手机扫码后在浏览器里选文件上传
2. **专属文件夹** —— 数据线或手机端工具把书放进 `/sdcard/Android/data/com.webook.watch/files`

Android 10 及以下（多数老款手表）不受此影响，内置文件管理器可正常浏览。

## 技术实现

| 能力 | 常见实现 | 本项目 |
|---|---|---|
| 排版 | CSS + Range 测量 / 自带排版引擎 | `TextPaint.breakText` 断行 |
| 分页 | JS 二分 + 容器校验 | 纯函数 `PagePacker.pack()`（可 JVM 单测） |
| 绘制 | DOM | Compose `Canvas` 逐行 `drawText`，位置由分页结果决定 → 不会有半截字 |
| EPUB | JSZip | `java.util.zip.ZipFile` + `XmlPullParser` |
| MOBI | JS PalmDOC | Kotlin `PalmDoc.decompress` |
| 朗读 | Web Speech API | 系统 `TextToSpeech` |
| 二维码 | 引 QR 库 | 手写编码器（`data/QrCode.kt`，<300 行，省掉 100~300KB 依赖） |
| 传书 | 云盘中转 | 手表内置 HTTP 服务（`data/WifiTransfer.kt`，局域网、只收上传） |
| 存储 | IndexedDB | 应用私有目录 JSON（无需权限、无需数据库） |

**内存友好设计**：手表堆上限常常只有 96 MB。EPUB 用 `ZipFile` 逐章读，插图**不预抽取** —— 翻到哪页才去压缩包里读那一两张，按屏幕宽度降采样、`RGB_565` 解码，LRU 最多缓存 12 张。

**性能实测**（华为 NIK-AL00 / 1102 章的书）：目录滚动中位 8 ms、90 分位 12 ms、卡顿率 8.2%。

## 自己编译

需要 JDK 17+ 与 Android SDK（platform 34 / build-tools 34.0.0）。

```bash
export JAVA_HOME="/path/to/jdk"
export ANDROID_HOME="/path/to/android-sdk"

gradle testReleaseUnitTest   # JVM 单测（60 个）
gradle assembleRelease       # 有正式 keystore 时自动签名
gradle lintRelease           # 静态检查
```

构建号由 `build-number.txt` 自动递增，**不要手改**。签名配置见 [SIGNING.md](SIGNING.md)，版本号规则见 [VERSIONING.md](VERSIONING.md)。

## 已知限制

- 带 DRM 的 EPUB、亚马逊 **KF8 / KFX** 不支持（会明确提示，不会静默失败）
- **PDF** 不打算支持：小屏重排体验差
- 朗读依赖手表自带的 TTS 引擎，部分精简 ROM 未内置（此时点击朗读没有声音）
- 文字两端对齐默认关闭，开启后段落末行不参与对齐
- **漫画模式尚未在真机验证**：开发机只有 Android 10 的华为手表（装不上新包），判定与展平逻辑有单测覆盖，UI 层只在模拟器验证过
